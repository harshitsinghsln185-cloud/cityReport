# Hero Text Decisions — Phase H1

This document specifies the approved final copy for the hero sections of all five target pages, adhering to the following rules:
- Plain English, no filler words, no em dashes, no exclamation marks.
- One `h1` per page, shortened to at most 8 plain words.
- Eyebrow: 1 to 3 words.
- Description: exactly one sentence, at most 22 words.
- Primary action and at most one secondary action.
- All non-essential visual cards, unverified claims ("36 regions", "24-48h SLA", "SOR Audited", "escrow"), duplicate stats, and badges removed from the hero.
- Functional elements (such as the track search console and the inquiry form) remain in their content positions below the hero.
